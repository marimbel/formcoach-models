# Models C and D

Neither model is trained, so both are evaluated only on the test participants' videos.

- **Model C (pose):** share of test frames where all needed joints are visible (≥ 0.5); rep-count accuracy against a hand count for each test video; frames per second and latency on the demo phone.
- **Model D (image):** for 20–30 test crops, each member rates whether the drawn correction matches the cue (yes/no) and is clear (1–5). Also record generation time and cost per image.
